# Documentación

Esta carpeta `docs/` contiene documentación del proyecto: diagramas, guías de configuración, ejemplos de `application.yml`, instrucciones para levantar los servicios y cualquier otro material de referencia.

Actualmente este archivo se creó para inicializar la carpeta `docs`. Si quieres que añada contenidos concretos (por ejemplo: `architecture.md`, `kafka-setup.md`, `docker-compose.override.yml` para MariaDB, o `service-application-examples/` con `application.yml` por servicio) dime cuáles y los creo.
